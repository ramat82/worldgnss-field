Complete Field Manual — English edition

This online edition is the English translation of the French master field manual based on audited application version 1.3.2.18 — versionCode 39. The original 70-page illustrated French PDF remains the visual reference for capture markers C01–C44.

1. Purpose of this manual and conventions

This manual describes WorldGNSS Field from a field user's point of view: project preparation, CRS selection, survey management, point measurement, topographic drawing, stakeout, calculations, DXF adjustment, scan/image workflows, import, export and backup.

VERIFIED IN CODE — Procedures are based on the audited application. A function discussed during development but absent from the audited interface is not presented here as available.

1.1 Three labels used throughout the manual

LabelMeaning
VERIFIED IN CODEThe function, button or rule exists in the audited version.
WARNINGA condition, limitation or safety check to know before operating.
FIELD TIPA practical recommendation; it does not change the software rule.

1.2 Screen captures

The illustrated French edition uses 44 captures made in SIMULATION MODE. Functions requiring real GNSS hardware are explained from the code and are identified as such. Capture identifiers C01, C02, etc. are shared by all language editions.

3. Startup: language, REAL MODE or SIMULATION MODE

3.1 Choose the language

At startup WorldGNSS Field offers Automatic, Français, English and العربية. The choice is stored and the interface reloads in the selected language.

  1. Open WorldGNSS Field.
  2. Select English for this manual.
  3. Continue to the operating-mode screen.

3.2 Choose the operating mode

The mode is selected at session start and is not cosmetic: it determines the GNSS source and strictly separates Real and Simulation surveys.

SIMULATION MODE — WorldGNSS produces a simulated GNSS position. This is the mode used for the manual captures.
REAL MODE — Intended for a physical GNSS receiver and part of the Pro Pack in the current commercial architecture.

3.3 Configure Simulation

  1. Tap SIMULATION MODE.
  2. Enter or keep the proposed latitude, longitude and altitude.
  3. Select the simulation profile if requested.
  4. Confirm. The chosen position becomes the GNSS source for the session.
WARNING — A survey created in Simulation and a survey created in Real mode are not interchangeable. WorldGNSS refuses to open a survey from the wrong mode.

4. Home screen and general navigation

The Home screen displays the current context — active project, CRS and GNSS status — and provides access to the main modules. Bottom navigation available in several screens returns to Project, Survey, Stakeout and Plan.

CommandRole

ExitEnd the session; in Simulation, the simulated GNSS source is stopped.

5. CRS / Project: country, UTM zone and working CRS

WorldGNSS Field keeps geographic WGS84 as the pivot. The working CRS is used for displayed projected coordinates and calculations. Coordinates from an existing survey must never be reinterpreted solely from the phone's current position.

5.1 Open CRS selection

  1. Open Projects / Survey management.
  2. Tap Choose working CRS.
  3. In CRS / Project choose Locate, Manual, Simulation or Local.

5.2 Locate

Locate uses the Android phone position to determine the country and UTM zone. It is useful on site when the phone location represents the work area.

WARNING — For an existing survey, the phone position is not used to redefine its region. WorldGNSS relies on the survey's own WGS84 geography.

5.3 Manual and Simulation

These modes let you enter latitude and longitude in decimal degrees, useful for preparing a remote project or testing the worldwide CRS engine without travelling.

  1. Choose Manual or Simulation.
  2. Enter latitude and longitude.
  3. Confirm.
  4. Check detected country and UTM zone.
  5. Select the proposed CRS that matches the job.

5.4 Proposed CRS list

The main list is filtered by country. Relevant national/projected CRS and the corresponding WGS84/UTM system are prioritised; unrelated continental systems are kept out of normal field selection.

VERIFIED IN CODE — In Algeria, the INCT 2022 workflow retains the intended professional priority while WGS84 remains the transformation pivot.

5.5 CRS locking with an active survey

Once a survey is active, the session CRS is locked. Close the survey before changing CRS.

5.6 Opening a survey from another region

  1. Select a session CRS.
  2. Request the existing survey.
  3. WorldGNSS checks the survey's WGS84 region.
  4. The CRS is accepted only if valid for that region.
  5. A different country, incompatible UTM zone or hemisphere is rejected before activation.

6. Survey and project management

Survey Management is the administrative centre of the job: creation, opening, import, export, media, field log and backup.

6.1 Create a survey

  1. Check the working CRS.
  2. Tap New / Create survey.
  3. Enter the job name.
  4. Confirm; the survey becomes active.

In Simulation, the creation flow identifies the survey as a Simulation survey, including the _SIM suffix where applicable.

6.2 Open a survey

  1. Tap Open.
  2. Select the survey.
  3. WorldGNSS first checks Real/Simulation compatibility.
  4. It then checks the session CRS against the survey's WGS84 region.
  5. If both checks pass, the survey becomes active.

6.3 Close a survey

Closing deactivates the current job but does not delete it. This is especially useful before changing the session CRS.

6.4 Media and project information

The screen shows point count, CRS and topography folder. Notes and Photos summaries give access to project and point media.

6.5 Other menu

  • Topo programs: opens field modules.
  • Field log: displays recorded project events.
  • Complete ZIP backup: creates a survey archive.
  • Restore ZIP backup: validates then restores a WorldGNSS archive.
  • Re-authorize TOPOGRAPHIE folder: renews Android folder access.

7. GNSS connections and quality rules

7.1 Connections / Navigation screen

Navigation groups GNSS status, satellite count, DOP, precision, receiver, project CRS, projected coordinates, WGS84/UTM reference, active survey and RTK base state when available.

7.2 In Simulation

The simulated GNSS source feeds the screen. Hardware Bluetooth search and connection controls are disabled.

7.3 In Real mode

Real mode can scan Bluetooth devices, select a receiver, connect and disconnect. Android Bluetooth permissions may be requested. Dedicated ProMark controls and Emlid/base assistants are available from this area.

7.4 FIX, FLOAT, SINGLE and precision

StatusSurvey behaviour
RTK FIXNormally accepted for measurement.
RTK FLOATRejected by default; may be explicitly allowed in precision settings.
SINGLERejected by default; may be explicitly allowed. Auto survey does not accept it unattended.
SIMULATIONAccepted when the Simulation context is active.
No GSTPrecision remains unknown (PR ---). WorldGNSS does not invent a value; RTK FIX may still be accepted.

7.5 Data freshness

The engine distinguishes recent, ageing and frozen positions. In the audited code, a GGA younger than 2.5 s is recent and a position around 5 s old is considered frozen; stale data must not be treated as a current measurement.

7.6 Survey precision settings

By default the precision lock is enabled with a 0.050 m horizontal threshold. Optional PDOP, satellite-count and correction-age checks exist; their default values are PDOP 3.0, minimum 5 satellites and 10 s correction age when enabled.

7.7 Antenna height

The entered antenna height is subtracted from receiver altitude to obtain the ground-point altitude.

FIELD TIP — Check antenna height and precision lock before a measurement series. An antenna-height error affects all recorded Z values.

8. Emlid Reach and local base calibration

8.1 Emlid Reach assistant

The assistant does not automatically change Android Wi‑Fi. It guides the user to the receivers' web panels.

  1. Open the Emlid assistant from Navigation.
  2. For the base, connect the phone to the base Wi‑Fi.
  3. Test 192.168.42.1 and open the Emlid panel.
  4. Then manually change Android Wi‑Fi to the rover.
  5. For the rover, test 192.168.42.1; 192.168.10.12 is also proposed as a secondary address.
  6. Open the required panel and finish the assistant.

8.2 Local calibration on a known point

Base Calibration computes a local translation DX/DY/DZ only; it does not compute rotation or scale.

  1. Place the rover on the known station.
  2. Read rover position.
  3. Enter known X/Y/Z or select a point from the active survey.
  4. Compute DX, DY and DZ.
  5. Apply the translation or remove it with Clear.
WARNING — Use this module only when a pure translation is the correct model. For rotation + scale, use TRS2D.

9. Point surveying

9.1 Prepare the survey

  1. Create or open an active survey.
  2. Check CRS and antenna height.
  3. Check GNSS state and precision lock.
  4. Open Topo modules > Survey.

9.2 Identify the point

The point ID can be entered or automatically proposed. Use an explicit project naming convention when possible.

9.3 Measure a simple point

  1. Enter or verify the ID.
  2. Choose the category: TOPO, NETWORKS, VEGET., ROAD or DRAWING.
  3. Select the point/object type.
  4. Check FIX/precision and current coordinates.
  5. Tap MEASURE.
  6. WorldGNSS applies quality rules and antenna height, then saves the point in the active survey.

9.4 Height and precision

Displayed and stored height follows the current antenna-height rule. Measurement can be blocked when the active precision rules are not satisfied.

9.5 Note

A note may be attached to a point for description, condition, identification or field instructions.

9.6 Photo

A photo may be associated with a point. Keep media meaningful and verify project storage access.

9.7 Voice and sounds

Voice guidance and beeps provide operational feedback, including successful measurements and guided stakeout states where enabled.

9.8 DRAWING

The DRAWING category is intended for generic line/polygon work when a dedicated conventional object is not required.

10. Conventional symbols and measured objects

WorldGNSS groups field objects under TOPO, NETWORKS, VEGETATION, ROAD and DRAWING. An object may use a simple one-point measurement or a detailed reusable geometry.

10.1 Geometry principles

  • SIMPLE: one point where meaningful.
  • ORIENTED: two points.
  • CIRCLE: centre + edge, or three points on the circumference.
  • RECTANGLE: three points.
  • LINE: N points.
  • POLYLINE/POLYGON: N points.
  • TARGET: one specific measured target.

10.2 Detailed procedure

  1. Choose category and object type.
  2. If several modes exist, choose simple or detailed.
  3. Measure requested points in order.
  4. Follow the progress indicator.
  5. For a line or polygon, tap Finish when all vertices are measured.
  6. If a mistake occurs, use Cancel/Undo as appropriate. Already measured survey points may remain even if the object grouping is cancelled.

11. Editing points

  1. Open Edit point.
  2. Use search to filter the list.
  3. Tap a point to open its edit card.
  4. Edit ID, X, Y, Z or Type and confirm.
  5. Long-press to open Edit / Delete.
  6. The Add button creates a manual point and proposes the next Pn identifier.
WARNING — Manual coordinate editing changes project data. Verify the CRS and values before saving.

12. Survey map and STATIC mode

12.1 Map navigation

Use pan, zoom and GNSS recentering to inspect the active survey on the OSM background.

12.2 Inspect a point

Tap a visible point to inspect its identity and project information.

12.3 Build a polyline

  1. Choose the object class.
  2. Enter construction mode.
  3. Tap an existing point to add it as a vertex, or Measure to create a new GNSS point and add it.
  4. Repeat for the following vertices.
  5. Use Undo to remove the last vertex.
  6. Tap Finish when geometry is complete.

12.4 Delete an object

  1. Enter object-deletion mode.
  2. Tap the geometry.
  3. Confirm or cancel.

12.5 STATIC in Simulation

  1. Tap STATIC.
  2. Simulation switches to STATIC.
  3. Drag the GNSS head/position on the map.
  4. The dropped position becomes the simulated GNSS position used by calculations.
  5. Disable STATIC to restore the previous simulation profile.
WARNING — STATIC is a Simulation function. It must not replace or alter the real GNSS source in Real mode.

12.6 Viewing from Auto Survey

The map can be used to inspect automatically collected points and the geometry formed during the session.

13. Topographic plan and drawing

13.1 Draw

  1. Open Plan.
  2. Choose the class: wall, fence, kerb, axis, network, surface, etc.
  3. Tap survey points successively. If several overlap, select the correct point from the list.
  4. Use Undo if necessary.
  5. Tap Finish to save the geometry.

13.2 Geometry actions

Available actions depend on object type and can include selection, inspection and deletion.

13.3 Surface display

Closed geometries can be displayed as surfaces so their extent is readable on the plan.

14. Automatic survey

Automatic Survey records points according to a distance or time condition while applying the configured quality rules.

14.1 Modes

  1. Choose Distance or Time.
  2. Set the threshold.
  3. Configure precision/speed filters.
  4. Tap Start session.
  5. Use Pause / Resume if needed.
  6. Tap Stop to finish.
FIELD TIP — A distance mode is usually easier to interpret for a moving boundary or route; a time mode is useful when a regular temporal sampling is required.

15. Area measurement

15.1 Manual boundary survey

  1. Open Area.
  2. Tap Start to begin a new shape.
  3. Stand on each vertex and tap Add point.
  4. Check the shape drawn on OSM.
  5. Tap Close when the boundary has at least 3 points.
  6. Enter the shape name.

15.2 AUTO

Auto mode adds boundary points as movement reaches the configured condition, allowing a contour to be followed while moving.

15.3 Geometric checks

The module checks that the polygon is usable and protects against invalid boundary configurations such as problematic self-crossing.

15.4 Shapes

Saved shapes can be reopened from the Shapes list.

15.5 Map, capture and STATIC

The OSM map provides visual control. In Simulation, STATIC can place the simulated GNSS position on the map for training and workflow testing.

16. Tilt without IMU

This module estimates the ground point from several antenna positions while the pole tip remains fixed. It does not rely on an IMU.

16.1 Conditions

Good GNSS quality, sufficient geometric spread and a strictly stationary pole tip are essential. The module evaluates sample count, RMS and movement geometry.

16.2 Procedure

  1. Place the pole tip exactly on the point.
  2. Open Tilt without IMU.
  3. Tap Start.
  4. Keep the tip perfectly fixed and move the antenna around it to create sufficient sweep.
  5. Monitor FIX, PDOP, sample count, RMS, computed height and spread.
  6. When quality is reached the module may stop with a beep.
  7. Tap Validate; the corrected point becomes the latest survey position.
  8. Return to Survey and record it through the normal flow.

17. Point stakeout

17.1 Select a target

  1. Open Point stakeout.
  2. Tap Choose target to search by ID, or Choose on map.
  3. Verify target ID and coordinates.
  4. Start guidance.

17.2 Guidance

The screen displays direction and distance information toward the target and updates from the active GNSS source.

17.3 Orientation modes

Available orientation modes adapt the guidance reference to field use. Select the one that matches how the operator is moving and reading the screen.

17.4 Tolerance

The tolerance defines when the current position is considered sufficiently close to the target.

17.5 Simulated field movement

  1. In Simulation, tap Simulated field.
  2. WorldGNSS advances the simulated position toward the target using the dedicated profile.
  3. Stop when desired; Simulation returns to the previous profile at the reached position.

17.6 Measure the staked point

  1. Once on target, tap Measure.
  2. Confirm or enter the ID.
  3. WorldGNSS stores the actually measured position as a project point with a type indicating its stakeout origin.

18. Stakeout map selection

  1. Open Choose on map.
  2. Zoom/recenter if necessary.
  3. Tap the target point.
  4. Verify the selection.
  5. Tap Validate.

The selected target is returned to the stakeout screen and remains tied to the active project context.

19. Line stakeout

19.1 Define A and B

A and B can come from project points, field measurement or permitted manual input. They define the reference line.

19.2 Sign convention

Chainage/PK is measured from A toward B. Offset sign indicates the selected side of the line according to the module convention.

19.3 Compute and stake

  1. Select or measure A.
  2. Select or measure B.
  3. Verify that |AB| is not nearly zero; a line shorter than about 0.05 m is refused or flagged.
  4. Enter PK from A.
  5. Enter offset; 0 means on the line.
  6. Enter the target ID or keep the proposed one.
  7. Tap Calculate.
  8. Check sketch and coordinates.
  9. Tap Stakeout to open locked guidance.

20. Intersection

  1. Select or measure A and B.
  2. Select or measure C and D.
  3. Tap Calculate.
  4. Read intersection coordinates and on-segment / outside-segment status.
  5. Tap Stakeout to guide to the intersection or Measure to store the field point.
WARNING — The numerical intersection of two lines can exist outside one or both input segments. Always read the status, not only the coordinates.

21. Reference line — 7 methods

The Reference Line module groups seven field constructions around a base line, including chainage/offset style operations, division and parallel-line work.

21.1 General procedure

  1. Open Reference line and choose the method.
  2. Provide A and B.
  3. Provide C when required.
  4. Enter PK, distance, offset, side or division according to the method.
  5. Tap Calculate.
  6. Read the compact result or open Details.
  7. When several solutions exist, select the desired computed point using the radio buttons.
  8. Tap Stakeout or Measure as required.

21.2 Division

Division generates positions distributed along the reference geometry according to the requested division parameters.

21.3 Parallel line

Parallel-line methods construct a line at the requested lateral offset while retaining the direction of the reference line.

22. Custom CRS, local shift and TRS2D

22.1 Manage CRS

The CRS manager lists available systems and gives access to custom/local systems.

22.2 Edit or create a custom CRS

Custom definitions must be entered with care. A wrong datum, projection, unit, axis convention or parameter set can produce plausible but incorrect coordinates.

22.3 Create a local CRS by translation

  1. Measure the known point with validated GNSS.
  2. Enter local X, Y and Z corresponding to exactly the same point.
  3. Compute DX = Xlocal − Xmeasured, and DY/DZ likewise.
  4. Check the values.
  5. Use for CRS to save the local system.

22.4 Create local TRS2D

TRS2D adds rotation and scale to the planar translation.

  1. Open Manage CRS > Create local TRS2D.
  2. Verify that an active survey and a projected CRS exist; geographic WGS84 alone is not accepted as the working plane.
  3. Create at least two source/destination pairs. The source can be a project point, current GNSS measurement or manual input.
  4. Validate each pair before adding the next.
  5. Tap Calculate.
  6. Check translation, rotation, scale, RMS and residuals.
  7. Use for CRS only if quality is acceptable.

23. DXF adjustment

23.1 Load the drawing

  1. Open Topo modules > DXF adjustment.
  2. Tap Load DXF.
  3. Select a DXF file or browse a folder containing DXF files.
  4. Check preview and status.

23.2 Full adjustment by pairs

Use at least three source/destination control pairs for a controlled adjustment.

  1. Select a source control point on the DXF.
  2. Choose its field/project destination.
  3. Repeat for at least 3 pairs.
  4. Open Pair list to inspect or delete a pair.
  5. Tap Calculate.
  6. Check quality and residuals.
  7. Export only when the result is validated.

23.3 Alignment

Alignment is intended for a simpler geometric fit when the relationship is known to be adequately described by translation, rotation and scale.

23.4 Two-point alignment

  1. Tap source point A on the DXF.
  2. Choose field destination A′.
  3. Tap source point B sufficiently far from A.
  4. Choose destination B′.
  5. WorldGNSS computes translation, rotation and scale.
  6. Check preview and confirm.
  7. An optional third control point may be used to verify the fit without changing the computed parameters.

23.5 Move only

Translation-only mode shifts the drawing without rotation or scale.

23.6 Signature only

For a drawing already correctly georeferenced in the project CRS, Signature only adds the WorldGNSS project/CRS signature without recalculating geometry after user confirmation.

23.7 Outputs

After a valid operation, the workflow can expose actions such as Open, Share, Export and Send to Impl-CAD.

23.8 STATIC

In Simulation, STATIC can place the simulated GNSS position on the map while checking control points. It does not alter Real-mode GNSS.

24. Impl-CAD

24.1 DXF acceptance condition

Impl-CAD expects a drawing whose coordinate context is accepted for the active project. A calibrated/signed DXF can arrive directly from DXF adjustment. A raw drawing requires explicit confirmation only when the user certifies that it is already in the working CRS.

24.2 Load and select

  1. Open Impl-CAD.
  2. Select the DXF or arrive from DXF adjustment.
  3. Check CRS ACCEPTED status.
  4. Zoom/recenter.
  5. Enable or disable selection lock as needed.
  6. Select a point/vertex or segment.

24.3 Stake a point

  1. Select a point.
  2. Tap Stake point.
  3. WorldGNSS creates a locked target with origin IMPL_CAD.
  4. Point stakeout opens.

24.4 Stake a line

  1. Select a segment, or a usable vertex belonging to a polyline.
  2. Tap Stake line.
  3. A and B are sent to Line stakeout and locked.
  4. Enter PK/offset and stake it as a normal line.

24.5 GNSS / STATIC

GNSS recentering follows the active source. STATIC is available only in Simulation for manual map-position testing.

25. Scan adjustment

25.1 Formats and TIFF

The module works with common image sources such as JPG/JPEG and PNG. Simple TIFF is supported under the application's accepted format rules; unsupported TIFF encodings are rejected with an explanatory message.

25.2 Automatic provisional calibration

An uncalibrated image receives a provisional reference so it can be displayed: origin at the current GNSS position when available, provisional pixel size 1 m and orientation 0°. This is explicitly provisional and must not be confused with a real georeference.

25.3 Adjustment by control points

  1. Load the image.
  2. Tap a source point on the scan.
  3. Choose its destination: plan, current GNSS, project point or manual input.
  4. Repeat for at least 3 pairs.
  5. Check Pair list.
  6. Tap Calculate.
  7. Read RMS, maximum error, scale and rotation.
  8. Save calibration.

25.4 Alignment

The alignment workflow applies the same simple geometric logic as the corresponding DXF alignment when appropriate.

25.5 Main menu and outputs

The three-dot menu groups recalibration, signature/alignment actions and post-processing outputs, including transfer to Impl-Scan where available.

25.6 STATIC

In Simulation, STATIC helps test image control and stakeout workflows by moving the simulated GNSS position over the map.

26. Impl-Scan

26.1 Load the scan

  1. Open Impl-Scan or send the image from Scan adjustment.
  2. Select the image.
  3. WorldGNSS looks for the saved calibration for that image.
  4. Calibration is accepted only when image size and CRS match.

26.2 Point mode

  1. Choose Point.
  2. Tap the point on the image.
  3. WorldGNSS displays project coordinates.
  4. Tap Stake point to create a locked IMPL_SCAN target.

26.3 Segment mode

  1. Choose Segment.
  2. Tap endpoint A.
  3. Tap endpoint B.
  4. Check segment coordinates.
  5. Tap Stake line to send A/B to Line stakeout.

26.4 Selection lock and STATIC

Selection lock prevents accidental map/image movement while choosing geometry. STATIC is a Simulation-only positioning aid.

27. CSV / TXT import

27.1 Step 1 — file and destination

  1. In Survey Management tap Import.
  2. Choose CSV/TXT.
  3. Select the file.
  4. Choose destination: new survey or active survey.

27.2 Step 2 — CRS

Define the source CRS correctly before conversion into the working CRS. Do not assume a file is WGS84 merely because it has numeric X/Y fields.

27.3 Step 3 — columns and vertical reference

Map ID, X/Easting, Y/Northing and Z/height columns and specify the vertical interpretation required by the workflow.

27.4 Step 4 — summary and duplicates

Review detected rows, valid points, rejected lines and duplicate handling before committing the import.

27.5 Geographic check

WorldGNSS checks whether imported coordinates are plausible for the selected CRS/region.

27.6 End of import

After validation, points are added to the chosen destination and become available to project tools.

28. KML, Shapefile and DXF import

28.1 Choose the type

Select the correct format from the import workflow.

28.2 KML

KML is normally geographic WGS84. WorldGNSS converts its geometry to the working project CRS while preserving the geographic reference.

28.3 Shapefile

Shapefile import may contain points, lines and polygons. Source CRS must be known or correctly selected.

28.4 DXF

DXF import reads supported geometric entities into the project context. A DXF with unknown or untrusted coordinate reference should first be handled through the recalibration workflow rather than assumed correct.

28.5 Summary and validation

  1. Check file and destination.
  2. Check source CRS and working CRS.
  3. Check vertical reference.
  4. Review point, line, polygon and annotation counts.
  5. Review duplicates and errors.
  6. Confirm import.

29. Project exports

29.1 Available formats

Depending on the workflow and selected options, WorldGNSS can export project data to formats such as DXF, complete CSV, Shapefile, KML and a packaged field deliverable.

29.2 Choose output CRS

Always verify the target CRS. The output CRS determines exported projected coordinates and must match the recipient's requirements.

29.3 DXF

DXF export creates CAD geometry from project points and objects. The validated WorldGNSS workflow keeps existing 2D plan layers and can include true DXF POINT entities plus a separate 3D topographic layer for XYZ geometry.

29.4 Complete CSV and height

Complete CSV exports point attributes and coordinates. Verify whether the requested Z corresponds to the project/ground height convention used by the job.

29.5 Field package

  1. Choose PACK.
  2. Select desired elements: DXF, complete CSV, Shapefile, KML, Photos, Notes.
  3. Ensure at least one item is selected.
  4. Choose target CRS.
  5. Export.

30. Backups and field log

30.1 Complete ZIP backup

Create a complete WorldGNSS ZIP backup at important project milestones and at the end of the field day.

30.2 Restore a backup

  1. Choose Restore ZIP backup.
  2. Select a WorldGNSS ZIP.
  3. Read the summary: project, points, CRS, quality, media, integrity and warnings.
  4. Read the transactional restore warning.
  5. Confirm only when the content is expected.

30.3 Field log

The field log records useful project events so important operations can be traced later.

31. Simulation mode, Pro Pack and professional outputs

31.1 Simulation

Simulation is intended for learning, preparation, demonstrations and workflow testing without a physical receiver. It provides a controlled simulated GNSS source and, on OSM screens, STATIC where implemented.

31.2 Real

Real mode uses the connected GNSS receiver and the real quality/precision pipeline. In the current commercial architecture it belongs to the Pro workflow.

31.3 Professional outputs

Some professional outputs may be restricted according to the application's Free/Pro commercial rules. A restricted output must not silently masquerade as a successful professional export.

32. Safety rules and important messages

  • Do not change the CRS while an active survey is locked to its session context.
  • Do not open a Simulation survey in Real mode or a Real survey in Simulation.
  • Do not interpret stale GNSS data as a current measurement.
  • Do not invent precision when GST information is absent; PR --- means unknown precision.
  • Check antenna height before measuring.
  • Read FLOAT/SINGLE acceptance settings before field use.
  • For DXF or scan workflows, distinguish a provisional/display calibration from a validated georeference.
  • Review RMS and residuals before accepting TRS2D, DXF or Scan transformations.
  • Back up the survey before major imports, restorations or end-of-day delivery.

32.1 Do not confuse phone position with survey region

The phone location can help initialise a new project or detect a region, but an existing survey carries its own geographic context. WorldGNSS must not redefine that survey solely because the phone is currently somewhere else.

33. Example: a complete field day

  1. Start WorldGNSS Field and choose the language.
  2. Choose REAL MODE on site with the Pro workflow, or SIMULATION MODE for office training.
  3. Open Projects and define the CRS: Locate or enter the region manually, check country and UTM zone, then select the working CRS.
  4. Create the survey and give it a clear job name.
  5. In Real mode, open Connections, connect the receiver and check FIX, precision, satellites, DOP and base state. In Simulation, verify the simulated source.
  6. Set antenna height and survey precision rules.
  7. Open Survey, choose TOPO / NETWORKS / VEGETATION / ROAD types and measure points.
  8. Add notes and photos where useful.
  9. Use Map or Plan to connect points and create project objects.
  10. For a boundary, use Area and save the shape.
  11. For design positions, select a Point target or use Line stakeout / Intersection / Reference line.
  12. For an external CAD plan, use DXF adjustment then Impl-CAD; for an image plan, use Scan adjustment then Impl-Scan.
  13. At the end, open Export / Share and create the requested DXF, CSV, SHP, KML or field package.
  14. Finally create a complete ZIP backup and store it safely.
