HOW TO PUBLISH ON GITHUB PAGES
------------------------------
1. Sign in to GitHub.
2. Create a NEW PUBLIC repository named:
   worldgnss-field

3. Upload ALL files and folders contained in this ZIP to the repository root.
   Important: index.html must be at the root, not inside another folder.

4. Open:
   Settings -> Pages

5. Under "Build and deployment":
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Click Save.

6. GitHub will display the final public address, usually:
   https://YOUR-GITHUB-USERNAME.github.io/worldgnss-field/

7. Open the published site and verify:
   - English page
   - FR link
   - AR link
   - Google Play button
   - LinkedIn button
   - screenshots

GOOGLE SEARCH CONSOLE — AFTER PUBLICATION
-----------------------------------------
1. Open Google Search Console.
2. Add the exact GitHub Pages URL as a URL-prefix property.
3. Complete ownership verification if requested.
4. Use URL Inspection on the home page.
5. Click "Request indexing".
6. Request indexing for:
   /index.html
   /fr.html
   /ar.html
